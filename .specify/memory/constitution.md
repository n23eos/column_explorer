# Column Explorer: принципы разработки

Версия 1.0.0, приняты 2026-09-19.

- Сохранять совместимость с Obsidian 1.8.7 и текущими настройками пользователя.
- Использовать TypeScript, Obsidian API, существующие CSS-переменные темы и Vitest проекта.
- Новые изменения вести через spec.md, plan.md и tasks.md в specs/. Историю openspec/ сохранить.
- Операции с файлами выполнять через API Obsidian. Не менять пользовательские данные при миграции UI.
- Подтверждать исправления содержательными регрессионными тестами, lint, coverage и сборкой.
- Не публиковать !notes, не сбрасывать чужие правки, не создавать коммиты и релизы без запроса.
- Проверять UI доступными средствами и честно фиксировать ограничения нативной проверки.
