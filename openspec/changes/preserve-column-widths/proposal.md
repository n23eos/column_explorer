## Why

Переключение файлов повторно расширяет вручную настроенную боковую панель. Пользователю нужна включённая по умолчанию фиксация ширины.

## What Changes

- Кнопка «Зафиксировать ширину колонок» в desktop-панели, активная по умолчанию.
- Тот же переключатель в настройках плагина с пояснением приоритета фиксации.
- Сохранение выбора между запусками, включая безопасный дефолт для старых установок.
- Ручное изменение ширины колонок остаётся доступным.

## Capabilities

### New Capabilities

- `column-width-lock`: запрет автоматической подгонки ширины панели при сохранении ручного изменения колонок.

### Modified Capabilities

Нет.

## Impact

Настройки и их нормализация, desktop toolbar, autoResizePanel, локали, тесты. Новых зависимостей нет.
