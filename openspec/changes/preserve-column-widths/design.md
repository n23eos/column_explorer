## Context

Существующий TypeScript-плагин Obsidian: view.ts управляет панелью, column.ts сохраняет ширины по путям папок, settings.ts хранит настройки, pure.ts нормализует данные. Vitest использует happy-dom и моки Obsidian. OpenSpec подключён к существующему проекту без переработки кода.

## Goals / Non-Goals

**Goals:** блокировать setSize панели при фиксации и сохранять существующий ручной resize.

**Non-Goals:** менять число колонок, масштаб мобильного UI или формат сохранённых ширин.

## Decisions

Ввести lockColumnWidths=true и общий guard в autoResizePanel: он покрывает render и drag. Сохранить autoPanelResize как отдельное существующее предпочтение: снятие фиксации возвращает прежнее поведение с учётом этой настройки. Простая смена дефолта autoPanelResize не защищает старые установки с сохранённым true.

Настройка доступна в декларативном и классическом интерфейсе настроек, как требует существующая проверка полноты. Кнопка с иконкой ruler, aria-pressed и стабильным переведённым названием; доступна с клавиатуры. Не смешивать её с существующей фиксацией количества колонок. Состояние обновляется при render для нескольких открытых видов.

## Risks / Trade-offs

Два связанных переключателя → документировать, что снятие фиксации разрешает подгонку только при включённой настройке автоподгонки.
Приватный API Obsidian → оставить существующие проверки sidebar/mobile/collapsed.

## Migration Plan

Отсутствующее или некорректное значение фиксации нормализовать в true; явное false сохранять. Старые размеры и настройки не менять. Откат к старой сборке игнорирует новое поле.
