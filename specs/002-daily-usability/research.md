# Decisions

- Использовать отдельный FuzzySuggestModal для поиска имён по всему хранилищу. Он не зависит от включённости встроенного поиска и не требует нового API. Альтернатива: приватный API core search, отклонена ради совместимости.
- Счётчик фильтра отражает уникальные совпавшие файлы в отрисованных колонках, включая ещё не загруженные части списков.
- Панель desktop использует существующие операции и выбранные пути, без нового хранилища состояния.
- Quick Look получает снимок упорядоченных видимых файлов, пропускает исчезнувшие; новый владелец содержимого на каждый переход предотвращает устаревшие асинхронные превью.
- Сортировка использует существующий columnSortModes и общее меню, без миграций.
- Документация API: Context7 для Obsidian API не дал совпадений, публичные страницы вернули Not Found. Совместимость проверена по установленным официальным obsidian.d.ts 1.13.1: FuzzySuggestModal и inputEl доступны с 0.9.20; используются публичные API.
- Production bundle превысил существующий лимит 327680 байт после локализации. Включено штатное minifyWhitespace esbuild; лимит и имена символов сохранены.
- Ревью выявило неоднозначность источника Quick Look для файлов, одновременно видимых в корне и виртуальном списке. Контекст задаётся явной глубиной колонки; регрессия проверяет оба порядка.
