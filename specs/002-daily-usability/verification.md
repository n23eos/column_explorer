# Проверка повседневного удобства

Дата: 2026-09-23.
Источник требований: текущий запрос пользователя и spec.md.

## Выполнено
- Фильтр показывает область действия и количество уникальных совпавших файлов в открытых колонках. Поиск по хранилищу сохраняет запрос, ищет имена/пути и соблюдает исключения.
- Desktop-панель выделения: количество, копирование, перемещение и снятие. Escape снимает выбор раньше фильтра, скрытые и удалённые элементы исключаются, доступное состояние синхронизировано.
- Компактная сортировка в заголовках: поле, направление, значок общей/индивидуальной настройки, прямое меню и восстановление фокуса.
- Quick Look: порядок исходной колонки, предыдущий/следующий файл, счётчик, стрелки, обработка исчезнувших файлов и устаревшего асинхронного содержимого.
- Мобильная строка поиска занимает полную ширину; сортировка остаётся в одной строке заголовка. Недоступная навигация использует disabled.
- Отмена перемещения сообщает восстановленные, пропущенные и ошибочные элементы. Добавлены доступные имена изображениям/PDF.
- Новые строки переведены во все 10 локалей. README и CHANGELOG обновлены; версия не повышалась.
