# Implementation Plan: Повседневное удобство

Date: 2026-09-23. Spec: [spec.md](spec.md)

## Summary
Расширить текущие DOM-компоненты: фильтр и панель выделения в view, сортировку в column/menus, Quick Look в modals/preview.

## Technical Context
TypeScript 5.9, Obsidian API (совместимость 1.8.7), Vitest 4.1, happy-dom, esbuild. Никаких новых зависимостей. Настройки сортировки существующие, остальное состояние временное. Цель: не добавлять полный обход хранилища при каждом рендере; поиск по всему хранилищу только по запросу пользователя.

## Constitution Check
Пройдена до и после проектирования: текущий стек, сохранность данных и правок, локализация, регрессии, обязательные проверки. !notes исключён через существующий паттерн. Публикации нет.

## Project Structure
src/view.ts: фильтр, выделение, контекст предпросмотра.
src/column.ts и src/menus.ts: сортировка.
src/modals.ts и src/preview.ts: поиск и Quick Look.
src/locales/: все переводы. styles.css: адаптивная компоновка.
tests/: существующий Vitest и новые сценарии.

## Delivery
US1 и US2 выполняются главным агентом. US3 и US4 независимы после согласования интерфейсов; один ответственный за файл. Общие CSS и локали интегрирует главный агент. Затем независимое ревью, проверки и UI.
