# UI contract

- Фильтр: понятная подпись, status со счётчиком, кнопка поиска во всём хранилище, очистка.
- Выделение: desktop toolbar с количеством, копированием, перемещением и закрытием. Фокус возвращается к колонкам после закрытия.
- Сортировка: button в заголовке папки, подпись порядка и направления, menu с наследованием.
- Quick Look: предыдущий/следующий, status позиции; границы disabled; стрелки не перехватывают управление медиа и полями.
