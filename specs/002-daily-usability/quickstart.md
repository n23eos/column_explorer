# Проверка

1. npm test; npm run lint; npm run test:coverage; npm run build.
2. Открыть плагин с папками и несколькими файлами: фильтр должен объяснить область и число совпадений. Поиск по хранилищу находит файл из другой папки.
3. Выбрать несколько файлов: панель показывает число, копирование и перемещение действуют на выбор. Escape снимает выбор перед фильтром.
4. Изменить сортировку в заголовке, вернуть общую; проверить узкую колонку.
5. Quick Look: стрелки, кнопки, счётчик, границы и быстрое перелистывание.
6. Светлая/тёмная тема, desktop 320/760/1280, mobile 375; консоль без ошибок. Нативные ограничения фиксировать отдельно.
