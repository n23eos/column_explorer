# Data model

- Filter: строка запроса, число уникальных совпавших файлов в открытых колонках. Временное состояние.
- Selection: существующие multiSel и multiSelDepth. Панель производна от них.
- Quick Look: упорядоченный снимок файлов и текущий индекс. На переходе исключаются удалённые файлы; без циклического перехода за границы.
- Sort: существующая карта columnSortModes, отсутствие значения означает наследование sortMode.
