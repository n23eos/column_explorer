# Feature Specification: Повседневное удобство

## User Scenarios & Testing

### US1 - Понятный фильтр (P1)
Пользователь понимает, что фильтр действует на открытые колонки, видит число совпавших файлов и может искать имя во всём хранилище.
Independent test: ввести имя, проверить счётчик, очистить фильтр, открыть поиск по хранилищу с тем же запросом.
Acceptance: папки остаются доступны для перехода; совпадения считаются без папок и повторов; пустой результат явно обозначен; поиск доступен с клавиатуры и на мобильном.

### US2 - Управление выделением (P1)
При множественном выделении на компьютере появляется панель с числом элементов, копированием, перемещением и снятием выделения.
Independent test: выбрать несколько файлов, скопировать, переместить, отменить выделение через кнопку и Escape.
Acceptance: Escape сначала снимает выделение, затем фильтр; панель исчезает при смене контекста и удалении выбранных файлов; мобильная панель сохраняется.

### US3 - Видимая сортировка (P2)
В заголовке каждой папки виден действующий порядок; он меняется нажатием на индикатор.
Independent test: установить индивидуальную сортировку, поменять общую, вернуть папку к общей.
Acceptance: подпись отражает направление и наследование, доступна клавиатурой, помещается в узкую колонку.

### US4 - Перелистывание Quick Look (P2)
Предпросмотр позволяет переходить по соседним видимым файлам без закрытия окна.
Independent test: открыть средний файл, перейти вперёд/назад кнопками и стрелками, проверить счётчик и границы.
Acceptance: порядок совпадает со списком, папки пропущены, скрытые фильтром файлы не попадают, пустой/удалённый файл обработан, редактор не переключается.

### Edge Cases
- Нет совпадений; отключённый поиск в диаграмме; отсутствующий встроенный поиск.
- Выбранный файл удалён или перемещён, активен фильтр, виртуальная колонка недавних.
- Один файл в Quick Look; быстрое переключение при асинхронном чтении; фокус в медиа.
- Ширины 320/760/1280 и мобильная ширина 375, светлая и тёмная тема.

## Requirements
- FR-001: Явная область фильтра, счётчик и поиск имён по хранилищу с сохранением запроса.
- FR-002: Панель выделения и предсказуемый Escape, без скрытых целей операций.
- FR-003: Видимый и доступный контроль сортировки папки с наследованием общей настройки.
- FR-004: Quick Look с кнопками, стрелками, счётчиком и корректным освобождением предыдущего содержимого.
- FR-005: Перевести новые строки во все существующие языки.
- FR-006: Исправить обнаруженные ошибки связанных сценариев, сохранить данные и настройки.

## Success Criteria
- Все четыре сценария выполняются мышью и клавиатурой без открытия настроек.
- Перелистывание 10 файлов не требует повторного открытия Quick Look.
- Снять множественное выделение можно одним действием.
- Сортировка каждой папки определяется по её заголовку.
- Автоматические регрессионные проверки, lint, coverage и сборка проходят; доступная UI-проверка задокументирована.

## Assumptions
- Семантика одиночного клика и история навигации остаются прежними: пункты 1 и 4 не выбраны.
- Поиск по хранилищу ищет имена файлов, не содержимое заметок.
- Существующий мобильный режим сохраняется. Без новых зависимостей и публикации.
