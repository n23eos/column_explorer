# Возврат кнопки прицела

Запрос владельца от 2026-10-30: вернуть быстрый показ пути папки текущей заметки.
На desktop отдельная кнопка locate рядом со сворачиванием колонок вызывает существующий revealFile для файла, активного в момент клика. Видны цепочка папок и выбранная заметка; мешающие фильтры сбрасываются. Без активной заметки навигация сохраняется. Есть локализованные подсказка и доступное имя. Настройки ширины и числа колонок сохраняются.
