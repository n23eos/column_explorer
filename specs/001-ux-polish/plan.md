# План реализации

1. Настройки/локали: единое управление шириной с сохранением фактического режима, условные поля, понятные названия.
2. Меню/модальные окна: группировка копирования, порядок удаления, допустимые цели перемещения.
3. Диаграмма: явные mount/suspend, dirty-флаг вне экрана, ленивый подсчёт слов и тесты гонок.
4. View/column: компактная панель, единая фильтрация виртуальных списков, клавиатура, эффективное обновление выделения, актуальная сортировка.
5. Интеграция: CSS, локализация, README/CHANGELOG, DOM-регрессии, браузерный стенд на тестовых данных, независимое ревью и проверки.

Владельцы файлов: root - view.ts, column.ts, mobile.ts, styles.css, view/column tests, документация; settings-agent - settings.ts, pure.ts (только нормализация ширины), locales/*, settings/sort tests; menus-agent - menus.ts, modals.ts, menus/modals tests, Menu mock; storage-agent - storage/* и storage tests. Никаких пересекающихся правок без передачи владения.

Ограничение: нативный Obsidian недоступен в CUA, browser preview использует подмену только API приложения. Внешний вид в Obsidian остаётся отдельной ручной проверкой.
