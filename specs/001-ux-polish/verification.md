# Результат проверки UX-исправлений

Дата: 2026-09-19.

## Выполнено

- Desktop-панель сокращена до создания, сортировки и дополнительных действий.
- Фильтр согласован с быстрым доступом, недавними файлами, календарным днём и клавиатурной навигацией. Скрытое выделение и предпросмотр очищаются.
- Кнопки доступны с клавиатуры; фокус сохраняется при переключении вида и избранного.
- Автоматическая ширина управляется одной настройкой; ручные размеры сохраняются, прежние сочетания настроек мигрируют с сохранением эффективного поведения.
- Зависимые настройки скрываются; новый API обновления вызывается только начиная с Obsidian 1.13.
- Копирование сгруппировано, удаление отделено, бессмысленные и конфликтующие цели перемещения исключены.
- Смена файла повторно использует списки; большие папки отрисовываются частями. Динамическая сортировка обновляется и сохраняет видимость выделения.
- Скрытая диаграмма не запускает пересчёт; слова считаются при выборе соответствующего режима.
- Обновлены переводы, README и CHANGELOG. Подключён Spec Kit для новых изменений.

## Проверено

- Полный набор: 665 тестов в 24 файлах прошли.
- Coverage: statements 89.28%, branches 82.55%, functions 84.92%, lines 93.25%. Все пороги проекта соблюдены.
- После типовых исправлений в тестах повторно прошли 61 тест затронутых двух наборов.
- npm run lint и npm run build прошли. main.js пересобран.
- Релизная версия подготовлена как 1.15.0. Размер main.js составляет 319125 байт при лимите CI 327680 байт.
- Миграция сохраняет прежний режим автоподгонки у существующих установок и использует ручной размер только для новых установок.
- npm audit не нашёл уязвимостей после обновления Vitest до 4.1.11.
- Независимое ревью относительно исходного снимка завершено без открытых замечаний.
- В браузерном стенде с настоящими исходниками и синтетическими данными проверены ширины 320/760, мобильный вид 375, светлая/тёмная тема, фильтр и очистка, быстрое меню и быстрый доступ. Ошибок и предупреждений в консоли нет.

## Ограничения

Нативная оболочка Obsidian недоступна. Геометрия сторонних тем, системные меню и реальные мобильные жесты требуют проверки в Obsidian. Браузерный стенд использует адаптер API и не является полной заменой такой проверки. Сборка не установлена в пользовательское хранилище и не опубликована.
