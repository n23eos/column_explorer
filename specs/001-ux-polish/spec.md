# Удобство и согласованность Column Explorer

Дата: 2026-09-19. Статус: реализация разрешена пользователем после UX-аудита.

## Текущая система

Obsidian-плагин 1.14.0. TypeScript + esbuild, CSS без фреймворка, Vitest/happy-dom. view.ts управляет колонками, column.ts рисует списки, settings.ts содержит декларативный и legacy UI настроек, menus.ts/modals.ts содержат операции, storage/ реализует диаграмму. Существующие изменения preserve-column-widths сохраняются. История OpenSpec остаётся на месте; Spec Kit используется для этой новой работы.

## Требования

1. Фильтр одинаково работает в папках, недавних, быстром доступе и списке файлов дня. Клавиатура и выделение используют тот же порядок, что видимый список.
2. Основные действия доступны Tab/Enter/Space. Путь диаграммы локализован. Выбранный клавиатурой элемент остаётся видимым.
3. Desktop-панель содержит «Создать», сортировку, «Ещё» и фильтр; редкие действия и режим количества колонок доступны в «Ещё». Мобильная функциональность сохраняется.
4. Одна настройка автоподгонки ширины панели сохраняет прежнее фактическое поведение комбинации autoPanelResize/lockColumnWidths. Ручная ширина каждой колонки сохраняется.
5. Общий раздел избранного и встроенных закладок называется «Быстрый доступ», локальное закрепление явно привязано к папке. Инструменты отделены от папок; существующие флаги функций сохраняются.
6. Копирование разных форматов сгруппировано; удаление отдельным последним блоком; меню расширений Obsidian работает. Выбор назначения исключает недопустимые перемещения.
7. Зависимые настройки показываются по необходимости в обеих версиях UI. Все десять локалей полны.
8. Скрытая диаграмма не пересканирует хранилище, слова считаются по запросу. При возвращении данные актуальны.
9. Навигация по файлам не пересоздаёт неизменные колонки без необходимости. Сортировка по изменению/размеру обновляется после modify с объединением событий, без потери выделения.

## Готовность

Регрессионные сценарии проходят, coverage соблюдает пороги проекта, lint/build успешны. Проверен доступный UI и документированы ограничения. Нет потери чужих изменений, сброса настроек, публикации, изменения версии или установки в рабочее хранилище.
