# План

Цель: пять согласованных изменений без миграции пользовательских настроек.
Этап: реализация и доступные проверки завершены.
Стек: существующие TypeScript, Obsidian API, CSS, Vitest; без новых зависимостей.
Исходный снимок: /tmp/column-explorer-before-004-20261020/.

1. Файловые операции: детальный результат move с совместимой числовой обёрткой; имя без расширения; подготовка в отдельной временной папке и переименование в итоговый путь при успехе. При сбое папка сохраняется с уведомлением, автоматического удаления нет.
2. View: сохранение cut-буфера по результатам; защита от параллельной вставки; общий предикат состояния списков; обновление по событиям; компактный select.
3. Поиск папок: отдельный modal и команда; раскрытие существующей ветки; переводы.
4. Проверки: содержательные регрессии, coverage, lint, сборка, лимит 327680 байт, diff; CUA-стенд с синтетическими данными, нативный UI если доступен.
5. Независимое ревью существенной логики, фиксация результата и ограничений.

Распределение: safe_fileops владеет fileops.ts/tests; filters_view владеет view.ts/CSS/tests; search_locales владеет search.ts/main.ts/локалями/tests. Главный агент владеет спецификацией, документацией и интеграционной проверкой.
Проверки: 725 тестов, coverage, lint, build, CUA-стенд и независимое ревью прошли; подробности в verification.md.
Следующий шаг: нативная проверка Obsidian после установки по запросу владельца.

Решение ревью 2026-10-20: сравнение stat после copy не доказывает отсутствие параллельной правки, а проверка пустоты перед trash не атомарна. Поэтому отменена автоматическая уборка после сбоя. Исходники и временный результат сохраняются; явно показывается путь, конечное имя свободно для повтора. Это заменяет первоначальный замысел журнала cleanup.
