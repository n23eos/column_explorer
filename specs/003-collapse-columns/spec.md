# Сворачивание промежуточных колонок

Запрос: 2026-10-19. Заметная кнопка со стрелкой влево первой в desktop-панели. По нажатию остаются корневая и последняя папка, выбранный файл и хлебные крошки сохраняются. Повторное нажатие возвращает прежний режим. Настройки замочка и ширины не меняются. Состояние сохраняется в workspace. Мобильный режим без изменений.
